HPU Control Box

The interface

A 4.3-inch color touchscreen.

Menu-driven, consistently dark and readable on the floor. Two clearly labeled entry screens take you straight to manual control or automatic cycle testing.

HMI cover screen — Cycle Test and Control entry points.

Three operating styles

Pick the mode that fits the moment.

Jog

Momentary

Coils energize only while the button is held, for maintenance, setup and single-step verification.

Turn On / Turn Off

Latching

One press opens the magnet (A), one press closes it (B). The state stays until the next command.

Cycle

Automatic

Repeats A and B to a target count, with configurable hold and interval times and optional position confirmation.

HMI screens

Manual control and automatic testing.

Every voltage, threshold and valve state is visible. Set it once, then run it repeatably.

Manual Control — live Hall voltages (mV), open/close thresholds, valve status, Jog buttons and E-stop in one view.

Cycle Test — target count, A/B hold and interval times, C follow (MTC only), and closed/open-loop mode.

Two builds, one controller

MAC and MTC modes. Verified by two Hall sensors.

MAC and MTC operating modes

MAC (default) drives directional valves A and B to open and close the magnet. MTC adds relief valve C (Y3), which follows A and B — Valve C and Jog C appear only in the MTC build.

MACValves A · B MTCValves A · B · C

Closed-loop position confirmation

Two redundant Hall sensors monitor the same magnet; either one can confirm position. Closed-loop checks against adjustable thresholds, while open-loop runs on timers alone.

CLOSEDSensor confirmed OPENTimers only

Safety built in

Protected on the production floor.

E-stop

Immediately de-energizes every output (Y1 / Y2 / Y3).

Sensor-disconnect detection

A reading below 100 mV is treated as a disconnected sensor, so OPEN never triggers falsely.

Position-timeout alarm

In closed-loop, no confirmation within the hold time stops the cycle and latches a fault.

Plug-and-play M12

Two keyed connectors — one for outputs, one for sensors; no discrete inputs needed.

Four interfaces

One 3.5-inch screen. Four interfaces.

Set the logic and interface to match each tool — NPN or PNP, Version A2 or A4. The box detects and displays the active logic automatically.

Operation screen — select NPN / PNP and Version A2 / A4.

What it does

Everything a PPe tool needs, on one box.

NPN / PNP dual logic

Auto-detected

Flip the logic switch to match the tool; the box auto-detects and displays NPN or PNP on screen.

A2 / A4 interface

Freely switchable

Move between the Version A2 and A4 operation interfaces to match the tool housing.

Magnet on/off & alert

Status display

Drive the magnet fully on and off, see the live state, and get an alert for abnormal tool conditions.

Manual & auto calibration

20-second auto

Calibrate manually, or run one-touch Auto Calibrate with a 20-second countdown.

Cycle testing

Custom interval

Set a custom cycle interval, watch the live count and elapsed time, then reset when done.

Portable power

Cordless

The 2800 mAh battery runs up to 5 hours with PPe30 and 3 hours with PPe50.

On the screen

Demo, calibrate, and cycle.

Clear, consistent screens walk through every PPe function without a laptop.

Operation — NPN / PNP × A2 / A4, magnet on/off and live status.

Calibration — Auto Calibrate with a 20-second countdown.

Cycle — live cycle count, elapsed time and reset.

Connections

Every port, clearly labeled.

  • Three M12 outputs — A / C / B

    Male M12 5-pin, 4-pin and 3-pin connectors, all A-coded and clearly labeled.

  • NPN / PNP switch

    A physical toggle sets output logic; the active logic is shown on screen.

  • 24 V DC power

    Power the tool at 3 A @ 24 V DC, with a dedicated 1 A @ 24 V DC charging port.

  • Power switch & battery readout

    A top-mounted power switch turns the box on and off, and the digital readout shows the battery level from the cell voltage — it is not a charging indicator.
